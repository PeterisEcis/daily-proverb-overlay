# Daily Proverb Overlay — archive

One folder per day, written by the
[daily workflow](https://github.com/PeterisEcis/daily-proverb-overlay/blob/main/.github/workflows/daily.yml).
The code lives on `main`; this branch holds only what it produced.

| File | What it is |
| --- | --- |
| `overlay.jpg` | The composited image |
| `attribution.txt` | Full credit text, to publish with the image |
| `metadata.json` | Machine-readable record of the run |

Don't edit by hand: the workflow commits here every day, and the
[archive site](https://peterisecis.github.io/daily-proverb-overlay/) is rebuilt
from whatever is on this branch.
